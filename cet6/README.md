# 词序 · 29 天六级词汇计划

纯 HTML / CSS / JavaScript 网站，无依赖、无后端，适用于 GitHub Pages。

## 使用

下载解压，双击 `index.html` 即可开始。推荐发布到 GitHub Pages 后固定使用同一浏览器和网址，以便保留进度。

- 29 个主题，每天 20 个词，共 580 个精选练习词。
- 翻卡记忆、拼写自测、浏览器英文朗读（取决于系统语音支持）。
- 记住的词按 1、3、7、14 天间隔调度；之后每次记住延后 14 天。忘记重置为次日复习并加入生词本。
- “已完成”表示当天 20 个词都至少练习过一次，不表示全部掌握。
- 生词本、中英文搜索、学习记录 JSON 导入导出。
- 进度在本地 localStorage 保存；无账户和跨设备自动同步。更换域名、设备或清除浏览器数据会影响记录，请定期导出备份。

## GitHub Pages 发布

1. 在 GitHub 创建一个仓库，例如 `cet6-29days`。
2. 将本文件夹内的 `index.html`、`style.css`、`data.js`、`app.js`、`.nojekyll` 和 `README.md` 上传到仓库根目录（不要只上传 ZIP）。
3. 在仓库 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)`，保存。
4. 等待部署完成，在 Pages 页面查看网站地址。一般为 `https://你的用户名.github.io/cet6-29days/`。

本项目未绑定任何账户，压缩包不代表已创建远程 GitHub 仓库。GitHub 的界面和账户功能可能因账户配置不同而有所区别。

## 文件说明

- `index.html`：页面结构
- `style.css`：桌面和手机布局
- `data.js`：29 天主题与词汇数据，可自由补充
- `app.js`：交互、复习调度和进度管理

## 词库范围

这是一套用于六级备考的精选练习词，不是官方大纲完整词表，也不宣称覆盖全部六级核心词汇或按真题频次排序。中文为简明常用义；请结合真题和词典学习多义、词性、搭配与语境。

## 隐私

不使用追踪、广告、远程字体或外部脚本。学习记录不上传服务器。系统语音服务是否联网取决于浏览器和操作系统。

## 每日词汇故事

29 篇原创虚构英文故事，每篇覆盖当天 20 个词，配中文翻译。点击加粗词查看释义或加入生词本，支持按句连续朗读及停止。阅读不自动改变学习进度，可从故事进入当天拼写自测。`stories.js` 保存故事与译文。

## 翻译与写作专项

每个故事配套同主题原创中译英短段、参考译文、语言提示、英文写作题及可迁移示范句。素材涉及文化、社会发展、教育、科技与个人成长；不是历年真题原文，也不是官方命题或频次排名。短段训练有意短于完整考试，不模拟整卷。官方题型说明：https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm 。

翻译和写作草稿分别按日期计划日保存在当前浏览器 localStorage 中（lexicon29-writing-1 至 29），与原学习记录分开，不包含在学习记录导出中。无自动批改或评分。`exam.js` 保存练习。
